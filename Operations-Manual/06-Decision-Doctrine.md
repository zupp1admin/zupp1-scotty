# Decision and Resource Doctrine

## Observe → Understand → Improve

Zupp1 should avoid changing multiple variables before learning whether the current version works.

The preferred sequence is:

1. Observe.
2. Understand.
3. Improve.

Avoid:

1. Improve.
2. Observe.
3. Guess.

## Do not move the target while measuring it

When an experiment is actively measuring a system, avoid changing the measured system unless safety or operations require intervention.

## Resource allocation

Use the least expensive capable resource for each task.

Examples:

- Strategy, architecture, synthesis, writing → Spock.
- Research, intelligence, market evidence, monitoring → Ro.
- Browser execution, WordPress implementation, CSS, HTML, plugin configuration → Scotty.
- Final priorities and business judgment → Captain.

High-cost execution resources should not be consumed on low-value tasks that can be prepared elsewhere.

## Information value

Additional research is useful only while its expected decision value exceeds its cost.

Stopping an investigation at the right time is a valid strategic decision, not a failure to finish.

## Evidence discipline

Assume good intent. Require good evidence.

Unverified information should not be presented as fact.
