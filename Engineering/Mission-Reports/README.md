## Purpose

This directory preserves durable engineering mission reports, audits, intervention registers, verification evidence and implementation recommendations.

A mission report belongs here when it explains what was inspected or changed, why it mattered, what evidence supports the conclusion, what remains unknown and how future officers should proceed.

## Preservation routine

1. Create or materially revise the durable report.
2. Remove credentials, private customer information, temporary exports and unnecessary operational data.
3. Route the document to the appropriate canonical directory.
4. Use this directory for XO and cross-platform engineering mission reports.
5. Commit with a descriptive message.
6. Update this index when a new report is added.
7. Update an existing canonical document instead of creating uncontrolled copies.
8. Preserve status, evidence, intelligence gaps, decisions, rollback information and review triggers.

The mission is not complete until its durable documentation is discoverable in GitHub.
